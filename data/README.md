# Semantic Scholar citation data

`semantic-scholar-cache.json` is generated by
`scripts/update_citation_leaderboard.py`. It stores the stable mapping between
paper-note paths and Semantic Scholar paper IDs, allowing weekly refreshes to
use batches of up to 500 identifiers rather than repeating title searches.

The generator works with Semantic Scholar's public API. Setting the optional
`SEMANTIC_SCHOLAR_API_KEY` environment variable gives the updater a dedicated
rate limit; anonymous runs use the shared public pool and safely checkpoint
partial progress if throttled.

Use `semantic-scholar-overrides.json` only for reviewed exceptions. Keys are
note paths relative to `docs/`; values are 40-character Semantic Scholar paper
IDs (or `null` to intentionally exclude a note):

```json
{
  "CVPR2025/llm_reasoning/example.md": "649def34f8be52c8b66281af98ae884c09aef38b",
  "CVPR2025/others/not_a_paper.md": null
}
```

Do not hand-edit the generated cache or public
`docs/assets/data/citations.json` file.
